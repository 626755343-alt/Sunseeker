# 追光者 Sunseeker · 词汇抽查工具

Windows 解压后双击 `start.bat`。浏览器会打开 `http://127.0.0.1:8765/`；保持启动窗口开启，课堂结束按 Ctrl+C 关闭。

首次使用点“核对 T1 样本”：内置了从所给 T1 词汇 PDF 识别的 45 个候选词条，以及从授课 PPTX 和公开资料整理的释义。程序会自动给全部词条补充音标，并对缺失释义的词条联网查询；联网不通时先用内置词典补充。T1 样本在离线测试中 45 个词条均出现音标和英英释义候选。请逐项核对词形、释义和来源，点击“确认入题”并保存。未来课程中的专名或词组若词典没有收录，仍需手动填写；未经确认的词条不会进入抽查。课件图片 OCR 也可能有错字。

未来课程点击“导入新课程”，只选词汇 PDF 即可；同课 PPTX 和 Word `.docx` 文件均可选。Word 支持正文中“词条：英英释义”、词条下一段的释义，以及表格中左列词条、右列释义。程序在浏览器本机提取文字及图片释义，PPTX 优先，Word 补充缺失项。联网词典批量补充其余英英释义、音标与音频；网络不可用时使用内置 WordNet/CMU 词典。联机或内置词典都可能选到与本课不符的词义，核对页会标明来源。核对页可点“一键确认全部”确认所有未排除的有效词条，建议先浏览识别结果。查不到释义时仍可确认词条、保存题库，抽到该词时只显示音标并可尝试朗读；音标也缺失时，朗读按钮会尝试使用浏览器英文语音。老师可以之后编辑课程补充释义。

抽查时先只显示单词或词组，点击“揭晓答案”后显示音标和英英释义。“答对了”播放简短奖励音效并加分，“继续练习”抽下一道，本轮不会重复。空格可揭晓，回车可到下一题。可关闭音效。

课程保存在当前浏览器的本机存储中。定期使用“导出备份”保存 JSON；换浏览器或清理浏览器数据后，可点“恢复备份”。原始 PDF/PPTX 不会上传到服务器。只有查询词汇会发送到在线词典；PPT 图片 OCR 引擎和英文模型已随网站打包，不再依赖海外 CDN。

内置备用词库依据 Princeton WordNet 3.1 和 CMU Pronouncing Dictionary 构建。许可声明见 `dist/licenses/`。

开发者可在源码目录运行 `pnpm install`、`pnpm dev`、`pnpm test` 和 `pnpm build`。

## GitHub Pages 发布

仓库已包含自动发布配置：把源码推送到公开 GitHub 仓库的 `main` 分支后，在仓库 Settings → Pages 中把来源选为 GitHub Actions。网站会发布到该仓库的 GitHub Pages 地址。公开仓库请勿提交学生个人信息、导出的备份 JSON 或原始课件。
